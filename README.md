# Seulbi Lee Research Profile

This is a plain static site designed for GitHub Pages. It is intentionally built as a living research profile rather than a fixed CV.

## Update content

For ordinary updates, edit only `content.js` in GitHub's web editor. Add a presentation, award, or project by copying an existing item in the matching list. The page updates automatically from those entries.

## Publish with GitHub Pages

1. Create a new GitHub repository (for example, `seulbi-cv`).
2. Upload `index.html`, `style.css`, and this `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
5. Save. GitHub will show the public URL in the same area after a short wait.

Before publishing, consider replacing the phone number with a contact form or removing it if you do not want it public.
